# cli-tools — collection of CLI tools written in Python

Collection of CLI tools. Most evolved through personal needs and lived as
single scripts. They are now packaged for easier testing and installation.

## Installation

```bash
pip install .
```

or with pipx:

```bash
pipx install /home/infothrill/src/git/cli-tools/

pipx install git+https://github.com/infothrill/python-clitools.git#egg=clitools
```

## Requirements

Python 3.10+
